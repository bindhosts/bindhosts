#

Bezsystemowy plik hosts dla APatch, KernelSU i Magisk

W pełni samodzielny i automatycznie aktualizowany.

## Funkcje

- Sterowanie przez WebUI i przycisk akcji
- Współpraca z AdAway
- Bezsystemowy plik hosts przez montowanie menedżera, bind mount i OverlayFS
- Metody przekierowania: ZN-hostsredirect, hosts_file_redirect, open_redirect
