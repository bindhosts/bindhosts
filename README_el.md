# bindhosts

Systemless hosts για APatch, KernelSU και Magisk

Πλήρως αυτόνομο, αυτόματη ενημέρωση.

## Χαρακτηριστικά

- WebUI και έλεγχος κουμπιών δράσης
- Συνύπαρξη Adaway
- Systemless hosts μέσω προσάρτησης διαχειριστή, bind mount και OverlayFS
- Μέθοδοι ανακατεύθυνσης: ZN-hostsredirect, hosts_file_redirect, open_redirect

## Υποστηριζόμενοι Διαχειριστές Root

- [APatch](https://github.com/bmax121/APatch)
- [KernelSU](https://github.com/tiann/KernelSU)
- [Magisk](https://github.com/topjohnwu/Magisk)  <sup>([χωρίς WebUI](https://github.com/topjohnwu/Magisk/issues/8609#event-15568590949)👀)</sup>
